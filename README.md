# Доска объявлений — обновлённая версия

React + TypeScript + Vite. Старые объявления с сервера не загружаются. Вместо них показаны демонстрационные товары. Добавленные объявления сохраняются только в localStorage текущего браузера; для настоящего общего каталога понадобится сервер.

Запуск на Windows PowerShell:
```
npm.cmd install
npm.cmd run dev
```

Сборка: `npm.cmd run build`. Изображения демонстрационных товаров загружаются из Unsplash при наличии интернета.
